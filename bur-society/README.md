# Bur Society

Sito editoriale per **Bur Society** — accademia creativa e community esclusiva a Milano.

## Stack

- Next.js (App Router) + React
- Tailwind CSS
- Framer Motion

## Sviluppo

```bash
cd bur-society
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

## Struttura

```
src/
  app/           # Route: /, /academy, /society, /admission, /shop
  components/    # Layout, home, academy, UI
  lib/           # Fonts, copy, corsi
```

## Pagine attive

- **/** — Manifesto (Enter / Apply)
- **/academy** — Percorsi Doppiaggio e DJ & Prod
